Casos reales
Backend móvil

Snaps backend.

La API de Snaps está construida en Go y usa Redis para que la expiración de una nota sea parte del almacenamiento, no una tarea programada que intenta limpiar después. El servicio corre en DigitalOcean detrás de HTTPS y se despliega de forma repetible.

CódigoPush a main
PipelineGitHub Actions
ServidorDigitalOcean
RuntimeGo + Redis
Aplicación web

DGSC web app.

DGSC reúne frontend y rutas del servidor en Next.js. La aplicación está containerizada para mantener el mismo entorno durante la entrega y corre en una instancia de AWS EC2 con tráfico seguro por HTTPS.
