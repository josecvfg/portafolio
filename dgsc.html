El contexto

Una interfaz pensada para jugar afuera.

Llevar el marcador en una ronda de disc golf suele terminar en papel, notas improvisadas o cálculos mentales. DGSC concentra el puntaje, los jugadores y el campo en una sola vista que se puede usar rápido desde el teléfono.

La aplicación calcula el total mientras avanza la partida y guarda cada ronda en el perfil. La ubicación permite asociar el resultado con el campo correcto, para que el historial tenga contexto y no sea solo una lista de números.

Scorecard multijugador

Pares por hoyo, tiros de cada jugador y total automático durante la ronda.

Controles directos

Interacciones grandes y claras para registrar un resultado con el menor número de pasos.

Campos en el mapa

La ubicación vincula cada partida con el lugar donde realmente se jugó.

Historial personal

Fechas, compañeros y resultados quedan disponibles desde la cuenta del jugador.

Sistema

Un flujo corto, de punta a punta.

La interfaz y el servidor comparten una sola base para mantener el producto simple de operar.
