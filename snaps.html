La idea

Diseñar alrededor del olvido.

No toda nota merece convertirse en archivo. Snaps parte de una pregunta sencilla: ¿qué pasa si capturar algo no obliga a conservarlo? Cada nota recibe una duración y desaparece cuando el contador llega a cero. Eso cambia la experiencia completa, desde la interfaz hasta la forma de almacenar los datos.

La app también resuelve el acceso rápido con widgets para iOS y Android. Las notas importantes viven en la pantalla de inicio mientras son útiles, sin pedirle al usuario que abra la app cada vez.

Duración configurable

Cada snap puede vivir desde minutos hasta una semana. El tiempo restante siempre es visible.

Widgets nativos

WidgetKit y Android App Widgets muestran las notas en el inicio con una experiencia propia de cada plataforma.

Personalización

Fondos, tipografías, iconos y colores permiten diferenciar una nota de un vistazo.

Modo offline

La experiencia sigue disponible sin conexión y sincroniza el estado cuando la red vuelve.

Arquitectura

El timer también vive en el servidor.

La expiración no depende de que la app esté abierta. Cada capa tiene una responsabilidad concreta.

Cliente

Flutter

Una base para iOS y Android, caché local y renderizado de las notas.

Identidad

Supabase Auth

Sesiones y cuentas para sincronizar datos entre dispositivos.

API

Go

Creación, consulta y borrado de snaps con una API ligera.

Tiempo

Redis TTL

Cada nota se guarda con su expiración exacta. Redis elimina la clave al llegar a cero.
